Case Study: The Runaway FinOps Investigator

When autonomous agents encounter real-world infrastructure failures, unbounded execution loops turn minor API errors into severe token inflation. This live demo recreates that failure mode on an enterprise billing anomaly and demonstrates how our four architectural controls restore deterministic execution.

3. Architectural Mitigation: The Four Controls

1. Execution Budgets

Hard iteration ceiling stops runaway loops.

max_iterations: 3
on_exhaust: "escalate"

2. Model Routing

SLM for triage; Frontier for complex reasoning.

tier: "triage" -> "8B"
tier: "reason" -> "70B"

3. Prefix Caching

Frozen system prompts ensure cache hits.

prompt_prefix: frozen
cache_hits: active

4. Context Compaction

Prunes bulky raw JSON dumps after Observe.

filter: "strip_stack"
retain: "error_code"
